# Digital Content Billing & Subscription Platform

A production-style distributed billing and subscription platform built with
Java 27 and Spring Boot.

## Purpose

This project demonstrates practical microservice and distributed-system
engineering concepts through a realistic SaaS billing domain.

## Current Status

Architecture discovery in progress.

## Technology

- Java 27
- Spring Boot
- Maven
- PostgreSQL
- GitHub Actions
- Docker
- Kafka
- Kubernetes

> Technologies will be introduced incrementally when justified by the architecture.

## Learning Focus

- Microservice boundaries
- Distributed data ownership
- Event-driven architecture
- Resilience
- Idempotency
- Distributed transactions
- Saga
- Observability
- Containerization
- Kubernetes
- CI/CD
